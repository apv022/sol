Services

Apps on this computer. Choose which peers may open each one on the Peers tab.

Peers

Other machines running Sol that you've paired with. Each side chooses what it shares, and either can send the other files. Unpair one and its access ends instantly.

Files

Files you add here go on your shared files page, which peers can open if you share it with them (Peers tab). Files peers send you also appear here, marked with who sent them; only you can see those. Every file has a SHA-256 fingerprint so it can be checked.

Activity

Pairings, connections, files, and blocked attempts. Newest first.
