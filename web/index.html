Help the Tor network

Runs a Snowflake proxy so people in censored countries can reach Tor through this machine. It needs no open port and is not a relay. While on, it contacts the Tor Project and public STUN servers from your IP address, and uses some of your bandwidth.

Networks

Sol reconnects by itself when your network changes (for example turning a VPN on). Use this if your devices can't reach this computer.

Services

Peers

Other machines running Sol that you've paired with. Each side chooses what it shares, and either can send the other files. Unpair one and its access ends instantly.

Files

Files you add here go on your shared files page, which peers can open if you share it with them (Peers tab). Files peers send you also appear here, marked with who sent them; only you can see those. Every file has a SHA-256 fingerprint so it can be checked.

Activity
