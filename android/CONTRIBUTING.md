# Contributing to Sol for Android

This repository is **generated**: every release copies the `android/` folder of
[apv022/sol](https://github.com/apv022/sol) into it with `git subtree split`. Changes merged here
directly would be overwritten by the next release.

- **Pull requests:** open them against [apv022/sol](https://github.com/apv022/sol), changing files
  under `android/`. Its [CONTRIBUTING.md](https://github.com/apv022/sol/blob/main/CONTRIBUTING.md)
  has the rules (tests, `make check`, no third-party dependencies).
- **Issues:** either repository is fine; Android issues are welcome here.
- **Security problems:** privately, see
  [SECURITY.md](https://github.com/apv022/sol/blob/main/SECURITY.md).
